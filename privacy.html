Privacy Policy

Personal Health Readonly

Overview

Personal Health Readonly is a private single-owner tool that reads the owner's own Google Health activity, fitness, sleep, and health metrics/measurements for personal daily logs and trend analysis. All access to Google Health data is read-only; this tool does not write to Google Health.

This is not a public service and does not offer signups. This website displays no actual health data.

Data Collection and Storage

Retrieved health data and OAuth credentials are stored privately on the owner's assistant computer. No health readings or credentials are sent to this public website.

The owner's assistant infrastructure processes data on the owner's behalf for requested logs and trends. Google remains the original provider of the health data.

Data Use

Data is not sold or used for advertising.

Website Hosting

This website is hosted on GitHub Pages. GitHub may collect ordinary access logs under its own privacy policy. For details, see GitHub's Privacy Statement.

Google API Services

This tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking Access

You may revoke this tool's access to your Google account at any time via Google Account Connections.

Data Deletion

Deletion of retained private logs is available at the owner's request.

Contact

For questions or requests regarding this privacy policy, contact via GitHub.
